🚀 Ambiente de Desenvolvimento

API + Dashboard Local + MLflow

Use esta página para desenvolvimento. O dashboard Streamlit roda localmente e consome a API em http://localhost:8000 (ou a URL que você configurar).

📚 API Docs (localhost) 📊 Dashboard (localhost) 📈 MLflow (localhost)

Como Usar em Desenvolvimento

1) Inicie a API:
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

2) Inicie o Dashboard (em outro terminal):
streamlit run app/dashboard.py --server.port=8501

3) Inicie o MLflow (opcional, em outro terminal):
mlflow ui --host 0.0.0.0 --port 5000

4) Acesse os links acima (localhost) para começar!

⚠️ Dicas Importantes

• Se a API não estiver em localhost:8000, configure a variável de ambiente:
export API_URL=http://127.0.0.1:8000

• Use make run-api, make run-streamlit e make mlflow para facilitar

• Em Docker, use: docker-compose up
